# Ember Launcher

Launcher for Ember Client. Releases on this repo are what installed launchers download.

## This is not a virus

Windows may say "Windows protected your PC" when you open the download. That is SmartScreen. Ember Launcher is not signed with a paid certificate yet, so Windows shows this for a new download. The file is not a virus.

Ember Launcher signs you into Minecraft Java 1.21.11 and starts Ember Client. If Windows blocks it, click More info, then Run anyway.
